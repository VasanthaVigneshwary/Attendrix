## 2. Model Implementation Summary

ATTENDRIX employs the **FaceNet** deep convolutional architecture (Schroff et al., 2015) accessed via the `DeepFace` framework. FaceNet maps cropped facial crops directly into a compact 128-dimensional Euclidean space where distances directly correspond to a measure of facial similarity:

1. **Face Detection**:
   - The input image is received via HTTP multipart upload (either uploaded classroom photography or live browser webcam frames).
   - Multi-scale frontal face detection is performed using OpenCV's Haar Feature-based Cascade Classifier (`haarcascade_frontalface_default.xml`), operating at `scaleFactor=1.1` and `minNeighbors=5`.
   - To eliminate redundant bounding boxes generated by multi-scale detection across neighboring scales, custom **Non-Maximum Suppression (NMS)** with an Intersection-over-Union (IoU) threshold of $0.30$ filters overlapping boxes into clean, distinct face crops.

2. **Facial Embedding Generation**:
   - Each detected face region is extracted, color-space converted to RGB, and normalized.
   - The crop is fed through the pretrained FaceNet neural network.
   - The output is an $L_2$-normalized 128-dimensional embedding vector:
     $$\mathbf{e} \in \mathbb{R}^{128}, \quad \|\mathbf{e}\|_2 = 1.0$$

3. **Identity Verification & Cosine Distance**:
   - Query embeddings are compared against all registered student embeddings stored in the SQLite database.
   - The distance metric used is **Cosine Distance**:
     $$d(\mathbf{u}, \mathbf{v}) = 1.0 - \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|_2 \|\mathbf{v}\|_2}$$
   - If $\min_i d(\mathbf{u}, \mathbf{s}_i) \le \tau$, where $\tau = 0.40$, the student identity $\mathbf{s}_i$ is predicted with high confidence.
   - If the minimum distance exceeds $0.40$, the face is strictly categorized as **Unknown**.

## 3. Training Summary

### Why Training Curves Are Not Applicable for Pretrained Inference
In deep learning engineering, training loss and validation accuracy curves over epochs are artifacts generated exclusively when optimizing network weights via gradient backpropagation on a training split.

In ATTENDRIX:
- The system employs **pretrained FaceNet inference**. FaceNet was pretrained by research teams on millions of facial samples from large-scale face datasets (VGGFace2 / CASIA-WebFace).
- At deployment, the model operates purely in **inference mode** as a zero-shot representation extractor.
- No gradient descent, parameter updates, epochs, or batch-wise loss computations take place during attendance recording.
- Therefore, **fabricating artificial training accuracy or loss curves would be scientifically dishonest**. Pretrained inference does not produce training loss curves, and reporting genuine empirical test metrics is the standard scientific methodology.

## 8. Reflection: Alignment with Assignment 1 Objectives

In Assignment 1, the theoretical foundation and architectural blueprint for automated classroom attendance were formulated. The current implementation directly addresses and fulfills those foundational objectives:

1. **Elimination of Proxy Attendance**:
   - In Assignment 1, the primary risk identified was proxy attendance via manual sign-ins.
   - ATTENDRIX resolves this by requiring biometric facial verification via deep convolutional embeddings. Without a physical facial match passing the strict cosine distance threshold, attendance is impossible to mark.

2. **Automated Classroom Scalability**:
   - Assignment 1 hypothesized whether an AI model could process an entire classroom simultaneously.
   - By integrating multi-scale Haar cascades with Non-Maximum Suppression, multiple students sitting in different rows are extracted in a single photo, achieving the intended automation.

3. **Data Integrity & Auditability**:
   - Assignment 1 highlighted the necessity of tamper-proof attendance logs.
   - ATTENDRIX implements relational integrity with SQLite and SQLAlchemy. Session records enforce unique date-student constraints, and full timestamps (year, month, day, hour, minute, second) ensure transparent administrative audit trails.

4. **Practicality & Teacher Workflow**:
   - Rather than remaining an abstract machine learning model, ATTENDRIX provides a clean, responsive web interface suitable for everyday faculty use, featuring real-time attendance statistics, live webcam capture, and one-click CSV export for institute records.
