Evaluation & Model Performance

Model Architecture: Pretrained FaceNet (128-dim via DeepFace)

ATTENDRIX utilizes pretrained FaceNet – an Inception-ResNet deep convolutional network trained on massive facial benchmarks to map facial crops directly into a compact Euclidean space where distances directly correspond to facial similarity.

Why Training Curves Are Not Applicable

Training curves (loss/accuracy over iterations) are generated exclusively when training or fine-tuning weights from scratch. In ATTENDRIX, FaceNet is leveraged strictly for pretrained feature inference. Pretrained models require no backpropagation, epochs, or artificial training curves; reporting genuine inference metrics is the scientifically correct and academically rigorous standard.

Similarity Metric & Threshold Justification

Identity classification is determined via Cosine Distance:

Cosine Distance = 1.0 - (u · v) / (||u|| * ||v||)

Empirical evaluation establishes a threshold of threshold = 0.40. Embeddings with cosine distance ≤ 0.40 are identified; distances > 0.40 are strictly rejected as Unknown to prevent false attendance.

About ATTENDRIX

Project Introduction

ATTENDRIX is an automated classroom attendance system built as an academic project by a 3rd-year B.Tech Artificial Intelligence & Data Science student. It uses deep learning-based face recognition to identify registered students and automatically record their attendance.

Problem Statement

Traditional manual attendance is time-consuming, error-prone and susceptible to proxy attendance. ATTENDRIX solves this by automating the process using AI-based facial recognition.

Objectives

  • Detect multiple faces in a classroom image.
  • Recognise registered students using FaceNet embeddings.
  • Mark attendance automatically; reject unknown faces.
  • Prevent duplicate entries within the same session.
  • Provide a searchable, exportable attendance record.

Technology Stack

BackendPython, FastAPI, SQLAlchemy, SQLite
Deep LearningDeepFace, Pretrained FaceNet, TensorFlow / Keras
Face DetectionOpenCV Haar Cascade
FrontendHTML5, CSS3, Vanilla JavaScript
EvaluationScikit-learn, Matplotlib, Seaborn

Recognition Workflow

Input Image
  → Face Detection (OpenCV Haar Cascade)
  → Face Extraction (crop bounding box)
  → FaceNet Embedding (128-dim, via DeepFace)
  → Cosine Similarity vs Registered Embeddings
  → Identity (if distance ≤ 0.40) OR Unknown
  → Attendance Marking (duplicate-safe)
